# Job Description — Backend Software Engineer (Python)

> **SYNTHETIC DOCUMENT.** This job description was written for the Agent Capstone
> project. The employer, team and role are fictional. It does not describe a real
> vacancy.

- **Employer:** Northwind Freight Systems *(fictional)*
- **Team:** Platform Services
- **Location:** Remote (EMEA time zones)
- **Level:** Mid-level (Engineer II)

## About the role

Platform Services builds the internal APIs that power shipment booking, tracking
and invoicing. You will design, build and run Python backend services used by
other engineering teams and by external partners.

## Responsibilities

- Design and implement RESTful APIs consumed by internal and partner teams.
- Own services end to end: design, testing, deployment and production support.
- Model data and write efficient queries against relational databases.
- Review teammates' code and contribute to engineering standards.
- Take part in the team's on-call rotation (roughly one week in six).
- Work with product managers to break down and estimate features.

## Mandatory requirements

1. **M1** — At least 3 years of professional software engineering experience
   using Python for backend development.
2. **M2** — Experience designing and building REST APIs.
3. **M3** — Experience with relational databases (e.g. PostgreSQL, MySQL),
   including schema design and query performance tuning.
4. **M4** — Experience writing automated tests (unit and integration) and working
   with continuous integration (CI) pipelines.
5. **M5** — Experience with Git-based collaboration, including code review.
6. **M6** — Experience deploying and operating services on a public cloud
   provider (AWS, GCP or Azure).

## Preferred requirements

1. **P1** — Experience using Docker or other containerisation in production.
2. **P2** — Experience with Kubernetes.
3. **P3** — Experience with message queues or asynchronous task processing
   (e.g. Celery, RabbitMQ, Kafka).
4. **P4** — Experience mentoring or onboarding less experienced engineers.
5. **P5** — Experience with observability tooling (structured logging, metrics,
   tracing).
6. **P6** — Bachelor's degree in Computer Science or a related field.

## What we offer

- Fully remote with quarterly in-person team weeks.
- Annual learning budget.
- 25 days of annual leave.

## Role summary

The Customer Web Experience team owns the public booking site and customer
portal. This senior frontend role leads work on the React design system and on
performance for the booking flow.

## Requirements used by the panel

- 5+ years of professional frontend development.
- Expert-level React and TypeScript.
- Experience building and maintaining a component library or design system.
- Strong understanding of web accessibility (WCAG 2.1 AA).
- Experience with frontend performance budgets and Core Web Vitals.
- Nice to have: GraphQL, Storybook, Playwright.
